## 二、系统总体框架

系统总体框架可以分为 **5 个主要部分**：

### 1. 表现层（前端）
**技术栈**: Vue 3 + Element Plus + Vite

- **视图组件**: Chat.vue（聊天）、FunctionRouter.vue（多功能助手）、VoiceChat.vue（语音）、VideoChat.vue（视频）、Settings.vue（设置）
- **状态管理**: Pinia（auth.js、chat.js、settings.js）
- **路由管理**: Vue Router
- **工具模块**: Axios 请求封装、AI API 调用、Markdown 渲染

### 2. 服务层（后端）
**技术栈**: Django 4.2 + Django REST Framework

- **中间件**: CORS、缓存、限流、安全防护、错误处理
- **URL 路由**: RESTful API 路由设计
- **视图层**: ChatView、FunctionRouterView、VoiceViews、UserAuth、KnowledgeBaseViews
- **业务逻辑**: EnhancedAPI（多模型封装）、FunctionRouter（功能路由）、OptimizedStreamChat（流式响应优化）

### 3. 数据层
**存储方案**: MySQL + ChromaDB + 文件系统

- **关系型数据库** (MySQL): 用户数据、会话记录、消息内容、配置信息
  - 数据库名: `chatbot_db`
  - 主机: `localhost:3306`
  - 字符集: `utf8mb4`
  - 驱动: `pymysql`

- **向量数据库** (ChromaDB): 知识库文档、语义索引、向量检索

- **文件系统**: 
  - 聊天图片 (`/media/chat_images/`)
  - 用户头像 (`/media/avatars/`)

### 4. 外部 AI 服务层
**支持的 AI 模型**:

- 通义千问 (Qwen-Max/Plus/Turbo)
- OpenAI (GPT-4/GPT-3.5)
- Google Gemini (Pro/Flash)
- 月之暗面 Kimi
- 字节跳动 Doubao
- 深度求索 DeepSeek

### 5. 基础设施层
**支撑组件**:

- **认证授权**: JWT Token 认证、权限控制
- **实时通信**: WebSocket (Django Channels)
- **安全防护**: IP 封禁、速率限制、内容安全策略
- **性能优化**: 缓存中间件、数据库优化、流式响应优化

## 三、核心数据流

```
用户输入 → 前端组件 → Pinia状态管理 → Axios请求 → Vite代理(/api, /media)
    ↓
后端中间件(CORS/缓存/限流/安全) → URL路由 → 视图层 → 业务逻辑层
    ↓
┌─ 意图识别 → 功能路由 → 对应处理函数
│
├─ 聊天模式 → EnhancedAPI → 选择AI模型 → 流式响应 → 前端实时渲染
│
├─ 功能模式 → FunctionRouter → 笑话/故事/翻译/成语/文案等
│
├─ 知识库模式 → ChromaDB向量检索 → 增强上下文 → AI回答
│
└─ 语音/视频 → WebRTC → 语音识别 → AI处理 → 语音合成
```

## 五、各层详细说明

### 5.1 表现层

表现层是用户与系统交互的界面，采用 Vue 3 框架开发单页应用（SPA）。

**主要功能模块**：
- **聊天界面**: 支持多轮对话、流式响应显示、Markdown 渲染
- **多功能助手**: 提供笑话、故事、翻译、成语接龙、文案生成等功能
- **语音助手**: 支持语音输入输出、实时语音识别
- **视频通话**: 基于 WebRTC 的视频通话功能
- **系统设置**: 用户配置、API 密钥管理、头像上传

**状态管理**：
- `auth.js`: 管理用户登录状态、用户信息、头像
- `chat.js`: 管理聊天会话、消息列表、当前对话
- `settings.js`: 管理系统配置、主题设置

### 5.2 服务层

服务层是系统的核心业务逻辑层，基于 Django 框架开发。

**中间件层**：
- **CORS 中间件**: 处理跨域请求
- **缓存中间件**: 提高 API 响应速度
- **限流中间件**: 防止 API 滥用
- **安全防护**: 内容安全策略、IP 封禁
- **错误处理**: 统一异常捕获和响应

**视图层**：
- **ChatView**: 处理聊天请求，支持流式响应
- **FunctionRouterView**: 功能路由，根据意图分发到不同处理函数
- **VoiceViews**: 处理语音相关请求
- **UserAuth**: 用户注册、登录、密码重置
- **KnowledgeBaseViews**: 知识库检索和管理

**业务逻辑层**：
- **EnhancedAPI**: 封装多个 AI 模型的 API 调用，支持自动降级
- **FunctionRouter**: 功能路由，识别用户意图并分发
- **OptimizedStreamChat**: 流式响应优化，提高响应速度

### 5.3 数据层

数据层负责系统数据的持久化存储。

**MySQL 数据库**：
- 用户表 (User): 存储用户基本信息
- 用户配置表 (UserProfile): 存储用户配置、API 密钥、头像
- 会话表 (Conversation): 存储聊天会话信息
- 消息表 (Message): 存储聊天消息内容
- 密码重置令牌表 (PasswordResetToken): 存储密码重置令牌
- 语音通话记录表 (VoiceCallRecord): 存储通话记录

**ChromaDB 向量数据库**：
- 存储知识库文档
- 支持语义相似度检索
- 为 AI 回答提供上下文增强

**文件系统**：
- 存储用户上传的聊天图片
- 存储用户头像
- 存储 ChromaDB 向量数据

### 5.4 外部 AI 服务层

系统集成了多个主流 AI 大模型，提供多样化的 AI 能力。

**支持的模型**：
- **通义千问**: Qwen-Max、Qwen-Plus、Qwen-Turbo
- **OpenAI**: GPT-4、GPT-3.5
- **Google**: Gemini Pro、Gemini Flash
- **月之暗面**: Kimi
- **字节跳动**: Doubao
- **深度求索**: DeepSeek

**模型选择策略**：
- 用户可在前端选择使用的模型
- 系统支持自动降级，当主模型不可用时切换到备选模型

### 5.5 基础设施层

基础设施层为系统提供基础支撑能力。

**认证授权**：
- 基于 JWT 的 Token 认证
- Access Token 有效期 24 小时
- Refresh Token 用于刷新 Access Token

**实时通信**：
- WebSocket 支持实时消息推送
- Django Channels 实现 WebSocket 服务

**安全防护**：
- IP 黑名单机制
- 请求速率限制
- 内容安全策略 (CSP)
- SQL 注入防护

**性能优化**：
- API 响应缓存
- 数据库查询优化
- 流式响应优化
- 前端资源懒加载
