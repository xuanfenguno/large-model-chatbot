# 图5-1 后端（Django）模块化架构图

## 后端模块化架构设计说明

本系统后端基于 Python+Django+Django REST Framework（DRF）搭建 RESTful API 服务，采用 MVT（Model-View-Template）架构模式，结合模块化开发思想拆分业务模块，实现业务逻辑与数据访问的解耦。

---

## 应用模块详细说明

### 1. chatbot - 核心聊天业务模块

**功能职责**：
- 大模型调用：封装多个AI模型的API调用
- 对话上下文管理：通过会话ID管理多轮对话
- 图文交互：支持文本、图片、语音等多种交互方式
- 功能路由：根据用户意图路由到相应功能

**核心组件**：
- `Conversation` 模型：会话管理
- `Message` 模型：消息管理
- `FunctionRouter`：功能路由器
- `EnhancedAPI`：API包装器

---

### 2. user - 用户管理模块

**功能职责**：
- 用户注册：新用户注册功能
- 用户登录：JWT Token认证
- 身份认证：Token验证和权限控制
- 个人信息管理：用户信息修改、头像上传等

**核心组件**：
- `User` 模型：Django内置用户模型
- `UserProfile` 模型：用户配置扩展
- `UserLoginView`：登录视图
- `UserRegistrationView`：注册视图

---

### 3. model - 大模型配置模块

**功能职责**：
- 多厂商大模型API配置：支持6个AI模型提供商
- 状态检测：API可用性检测
- 动态切换：API调用失败时自动切换

**核心组件**：
- `ModelConfig` 模型：模型配置
- `EnhancedAPI` 类：多模型API包装器
- API自动切换机制

---

### 4. system - 系统配置模块

**功能职责**：
- 系统参数配置：全局参数管理
- 日志记录：系统日志记录和查询
- 异常处理：统一异常处理机制

**核心组件**：
- `SystemConfig` 模型：系统配置
- 日志记录器
- 异常处理器

---

### 5. common - 公共模块

**功能职责**：
- 通用序列化器：为各业务模块提供基础序列化器
- 权限控制类：自定义权限验证类
- 工具函数：通用工具函数库
- 异常处理中间件：统一的异常处理中间件

**核心组件**：
- `BaseSerializer`：基础序列化器
- `IsOwnerOrReadOnly`：权限类
- `utils.py`：工具函数
- `ExceptionHandlerMiddleware`：异常处理中间件
- `RateLimitMiddleware`：速率限制中间件

## 数据流向说明

### 1. 用户认证流程

```
前端 → /api/auth/login/ → UserLoginView → User模型 → 数据库
     ↓
返回 JWT Token
```

### 2. 聊天流程

```
前端 → /api/chat/messages/ → MessageViewSet → Message模型 → 数据库
     ↓
调用 FunctionRouter → EnhancedAPI → 外部AI服务
     ↓
返回 AI 响应
```

### 3. 模型配置流程

```
前端 → /api/model/config/ → ModelConfigViewSet → ModelConfig模型 → 数据库
     ↓
EnhancedAPI根据配置调用相应的AI服务
```

---

## 技术架构特点

1. **模块化设计**：各应用模块相互独立，通过接口交互
2. **MVT架构**：Model-View-Template清晰分层
3. **RESTful API**：标准化的API设计
4. **ORM抽象**：Django ORM实现数据访问解耦
5. **多模型支持**：支持6个AI模型提供商
6. **JWT认证**：无状态的用户身份认证
