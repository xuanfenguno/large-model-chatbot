## 图表清单

### 第4章 系统设计

#### 图4-1 系统整体架构图
**位置**: 4.1.1 系统架构设计  
**说明**: 展示系统的四层架构设计，包括用户界面层、服务层、数据层和外部服务层。  
**内容**:
- 用户界面层：Vue 3 SPA，包含前端模块化架构
- 服务层：Django REST Framework，包含后端模块化架构
- 数据层：MySQL/SQLite数据库
- 外部服务层：6个AI模型提供商（OpenAI、Google、Alibaba、Moonshot等）

#### 图4-2 核心实体E-R图
**位置**: 4.2.2 核心实体E-R图  
**说明**: 展示系统的核心实体及其关系。  
**内容**:
- auth_user (用户) → chatbot_userprofile (用户配置) [一对一]
- auth_user (用户) → chatbot_conversation (会话) [一对多]
- chatbot_conversation (会话) → chatbot_message (聊天记录) [一对多]
- auth_user (用户) → chatbot_passwordresettoken (密码重置令牌) [一对多]
- auth_user (用户) → chatbot_voicecallrecord (语音通话记录) [一对多]

#### 图4-3 前端模块结构图
**位置**: 4.3.1 前端模块设计  
**说明**: 展示前端的模块化架构设计。  
**内容**:
- 核心框架层：Vue 3、Vue Router、Pinia
- 视图层：12个页面组件（Home、Login、Chat、Register等）
- 业务逻辑层：auth.js、chat.js、settings.js、ai-api.js
- 工具层：request.js、i18n.js、ai-config.js、webrtc.js

#### 图4-4 后端模块结构图
**位置**: 4.3.2 后端模块设计  
**说明**: 展示后端的模块化架构设计。  
**内容**:
- 核心框架层：Django 4.2、DRF
- 路由层：urls.py、views.py
- 业务逻辑层：enhanced_api.py、function_router.py
- 数据层：models.py、serializers
- API服务层：api_base.py、knowledge_base.py
- 中间件层：rate_limit、Error Handling、cache_middleware

#### 图4-5 系统模块关系图

## 图表制作建议

### 图表类型

1. **架构图**: 使用UML图或流程图
2. **E-R图**: 使用标准E-R图格式
3. **模块图**: 使用方框图或层次图
4. **流程图**: 使用活动图或序列图

### 图表工具

1. **draw.io**: 免费在线绘图工具
2. **Lucidchart**: 在线绘图工具
3. **PlantUML**: 文本化绘图工具
4. **Visio**: Microsoft Office绘图工具
5. **Mermaid**: Markdown格式绘图

### 图表尺寸

- **宽度**: 16cm
- **高度**: 10cm
- **分辨率**: 300dpi
- **格式**: PNG、SVG、PDF

### 图表标注

1. **图号**: 图4-1、图4-2、图4-3...
2. **图题**: 位于图下方，居中
3. **图注**: 位于图题下方，解释图的内容

### 1. draw.io (推荐)
- **网址**: https://app.diagrams.net/
- **优点**: 免费、在线、支持多种图表类型
- **适用**: 架构图、E-R图、流程图

### 2. PlantUML
- **网址**: https://www.plantuml.com/
- **优点**: 文本化绘图、易于版本控制
- **适用**: 架构图、序列图、活动图

### 3. Mermaid
- **网址**: https://mermaid.js.org/
- **优点**: Markdown格式、易于集成
- **适用**: 流程图、序列图、甘特图

### 4. Lucidchart
- **网址**: https://www.lucidchart.com/
- **优点**: 在线协作、模板丰富
- **适用**: 架构图、E-R图、流程图

### 5. Visio

- **适用**: 架构图、E-R图、流程图

## 图表制作步骤

### 1. 架构图制作步骤

1. **确定架构层次**: 确定系统的层次结构
2. **绘制层次方框**: 绘制各层次的方框
3. **添加模块**: 在各层次中添加模块
4. **连接箭头**: 使用箭头连接各模块
5. **添加标注**: 添加模块名称和说明

### 2. E-R图制作步骤

1. **确定实体**: 确定系统的核心实体
2. **绘制实体方框**: 绘制各实体的方框
3. **添加属性**: 在实体方框中添加属性
4. **连接关系**: 使用连线连接各实体
5. **标注关系**: 标注关系类型（1:1、1:N、M:N）

### 3. 流程图制作步骤

1. **确定流程步骤**: 确定流程的各个步骤
2. **绘制流程节点**: 绘制各流程节点
3. **连接箭头**: 使用箭头连接各节点
4. **添加标注**: 添加节点名称和说明
