# AI聊天机器人系统备份方案

## 1. 备份概述

### 1.1 备份目的
确保系统数据安全，防止数据丢失，在发生故障时能够快速恢复系统运行。

### 1.2 备份策略
采用多层次备份策略，包括：
- **数据库备份**: 定期全量备份 + 增量备份
- **文件备份**: 用户上传文件定期备份
- **配置备份**: 系统配置文件备份
- **日志备份**: 操作日志和访问日志备份

### 1.3 备份范围
- 用户数据（用户信息、配置）
- 会话数据（会话列表、消息历史）
- 文件数据（用户上传文件、头像）
- 系统配置（环境配置、数据库配置）
- 应用代码（可版本控制）

## 2. 数据库备份

### 2.1 备份工具选择

#### 2.1.1 SQLite数据库
**适用场景**: 开发环境、小型部署

**备份命令**:
```bash
# 全量备份
sqlite3 db.sqlite3 ".backup 'backups/db-backup-$(date +%Y%m%d-%H%M%S).sqlite3'"

# 或使用cp命令
cp db.sqlite3 backups/db-backup-$(date +%Y%m%d-%H%M%S).sqlite3
```

#### 2.1.2 MySQL/MariaDB数据库
**适用场景**: 生产环境、大型部署

**备份命令**:
```bash
# 全量备份
mysqldump -u [username] -p[password] [database_name] > backups/db-backup-$(date +%Y%m%d-%H%M%S).sql

# 压缩备份
mysqldump -u [username] -p[password] [database_name] | gzip > backups/db-backup-$(date +%Y%m%d-%H%M%S).sql.gz

# 只备份结构
mysqldump -u [username] -p[password] --no-data [database_name] > backups/db-structure-$(date +%Y%m%d-%H%M%S).sql
```

### 2.2 自动化备份脚本

**文件位置**: `backend/scripts/backup_database.sh`

```bash
#!/bin/bash

# 数据库备份脚本
BACKUP_DIR="backups"
DATE=$(date +%Y%m%d-%H%M%S)
DB_NAME="chatbot"
DB_USER="root"
DB_PASSWORD="your_password"
DB_HOST="localhost"

# 创建备份目录
mkdir -p $BACKUP_DIR

# 备份数据库
echo "开始备份数据库..."
mysqldump -u $DB_USER -p$DB_PASSWORD -h $DB_HOST $DB_NAME > $BACKUP_DIR/db-backup-$DATE.sql

# 压缩备份文件
if [ $? -eq 0 ]; then
    gzip $BACKUP_DIR/db-backup-$DATE.sql
    echo "数据库备份成功: db-backup-$DATE.sql.gz"
else
    echo "数据库备份失败!"
    exit 1
fi

# 删除7天前的备份
find $BACKUP_DIR -name "db-backup-*.sql.gz" -mtime +7 -delete
echo "已清理7天前的备份文件"

# 备份成功后执行
echo "备份完成时间: $(date)"
```

**权限设置**:
```bash
chmod +x backend/scripts/backup_database.sh
```

### 2.3 定时任务配置

#### 2.3.1 Linux/Crontab配置

**编辑crontab**:
```bash
crontab -e
```

**添加定时任务**:
```bash
# 每天凌晨2点执行全量备份
0 2 * * * /path/to/chat/backend/scripts/backup_database.sh

# 每小时执行增量备份（可选）
0 * * * * /path/to/chat/backend/scripts/backup_incremental.sh
```

#### 2.3.2 Windows任务计划程序

**创建任务**:
1. 打开任务计划程序
2. 创建基本任务
3. 设置触发器（如每天凌晨2点）
4. 操作选择"启动程序"
5. 程序脚本: `cmd.exe`
6. 参数: `/c "cd /d C:\path\to\chat\backend\scripts && backup_database.bat"`

**Windows备份脚本** (`backup_database.bat`):
```batch
@echo off
set BACKUP_DIR=backups
set DATE=%date:~0,4%%date:~5,2%%date:~8,2%-%time:~0,2%%time:~3,2%%time:~6,2%
set DB_NAME=chatbot
set DB_USER=root
set DB_PASSWORD=your_password
set DB_HOST=localhost

mkdir %BACKUP_DIR%

echo 开始备份数据库...
mysqldump -u %DB_USER% -p%DB_PASSWORD% -h %DB_HOST% %DB_NAME% > %BACKUP_DIR%\db-backup-%DATE%.sql

if %errorlevel% equ 0 (
    echo 数据库备份成功: db-backup-%DATE%.sql
) else (
    echo 数据库备份失败!
    exit /b 1
)

echo 备份完成时间: %date% %time%
```

### 2.4 备份验证

**验证脚本** (`verify_backup.sh`):
```bash
#!/bin/bash

BACKUP_DIR="backups"
LATEST_BACKUP=$(ls -t $BACKUP_DIR/db-backup-*.sql.gz | head -1)

echo "验证最新备份: $LATEST_BACKUP"

# 解压并检查SQL文件
gunzip -c $LATEST_BACKUP | head -20

# 尝试导入到测试数据库
mysql -u $DB_USER -p$DB_PASSWORD -h $DB_HOST $DB_NAME\_test < <(gunzip -c $LATEST_BACKUP)

if [ $? -eq 0 ]; then
    echo "✅ 备份验证成功"
else
    echo "❌ 备份验证失败"
    exit 1
fi
```

## 3. 文件备份

### 3.1 用户上传文件备份

**备份目录结构**:
```
media/
├── avatars/          # 用户头像
├── uploads/          # 用户上传文件
└── backups/          # 文件备份
```

**文件备份脚本** (`backup_files.sh`):
```bash
#!/bin/bash

BACKUP_DIR="backups/files"
MEDIA_DIR="media"
DATE=$(date +%Y%m%d-%H%M%S)

# 创建备份目录
mkdir -p $BACKUP_DIR

# 备份用户头像
echo "备份用户头像..."
tar -czf $BACKUP_DIR/avatars-$DATE.tar.gz $MEDIA_DIR/avatars/

# 备份用户上传文件
echo "备份用户上传文件..."
tar -czf $BACKUP_DIR/uploads-$DATE.tar.gz $MEDIA_DIR/uploads/

# 备份成功后执行
echo "文件备份完成时间: $(date)"

# 删除7天前的文件备份
find $BACKUP_DIR -name "*.tar.gz" -mtime +7 -delete
```

### 3.2 日志文件备份

**日志目录**:
```
logs/
├── django.log        # Django应用日志
├── access.log        # 访问日志
└── error.log         # 错误日志
```

**日志备份脚本** (`backup_logs.sh`):
```bash
#!/bin/bash

BACKUP_DIR="backups/logs"
LOG_DIR="logs"
DATE=$(date +%Y%m%d-%H%M%S)

# 创建备份目录
mkdir -p $BACKUP_DIR

# 压缩日志文件
echo "备份日志文件..."
tar -czf $BACKUP_DIR/logs-$DATE.tar.gz $LOG_DIR/

# 清理旧日志
echo "清理30天前的日志..."
find $LOG_DIR -name "*.log" -mtime +30 -delete

echo "日志备份完成时间: $(date)"
```

## 4. 配置备份

### 4.1 环境配置备份

**备份文件**:
- `.env` - 环境变量配置
- `config/settings.py` - Django配置
- `frontend/.env` - 前端环境配置

**配置备份脚本** (`backup_config.sh`):
```bash
#!/bin/bash

BACKUP_DIR="backups/config"
DATE=$(date +%Y%m%d-%H%M%S)

# 创建备份目录
mkdir -p $BACKUP_DIR

# 备份环境变量（排除敏感信息）
echo "备份环境变量..."
grep -v "^[^#].*=[^#]*$" .env > $BACKUP_DIR/.env-$DATE 2>/dev/null || true
cp .env.example $BACKUP_DIR/.env.example-$DATE

# 备份Django配置
echo "备份Django配置..."
cp config/settings.py $BACKUP_DIR/settings.py-$DATE

# 备份前端配置
echo "备份前端配置..."
cp frontend/.env.example $BACKUP_DIR/frontend-env-$DATE

echo "配置备份完成时间: $(date)"
```

### 4.2 数据库结构备份

**导出数据库结构**:
```bash
mysqldump -u [username] -p[password] --no-data [database_name] > backups/db-structure-$(date +%Y%m%d-%H%M%S).sql
```

## 5. 多级备份策略

### 5.1 本地备份
- **频率**: 每天全量备份
- **保留**: 7天
- **位置**: 本地服务器

### 5.2 异地备份
- **频率**: 每周全量备份
- **保留**: 30天
- **位置**: 远程服务器/云存储

### 5.3 云存储备份

#### 5.3.1 使用Rclone同步到云存储

**安装Rclone**:
```bash
# Linux
curl https://rclone.org/install.sh | sudo bash

# Windows
# 下载安装包: https://rclone.org/downloads/
```

**配置云存储**:
```bash
rclone config
# 按提示配置云存储（如阿里云OSS、腾讯云COS、AWS S3等）
```

**同步脚本** (`sync_to_cloud.sh`):
```bash
#!/bin/bash

# 同步备份到云存储
rclone sync backups/ remote:chatbot-backups/ --progress

# 删除云存储中7天前的备份
rclone delete remote:chatbot-backups/ --min-age 7d

echo "云同步完成时间: $(date)"
```

#### 5.3.2 使用阿里云OSS备份

**Python脚本** (`backup_to_oss.py`):
```python
import oss2
import os
import datetime
import tarfile
import zipfile

# 配置OSS
access_key_id = os.getenv('OSS_ACCESS_KEY_ID')
access_key_secret = os.getenv('OSS_ACCESS_KEY_SECRET')
endpoint = 'https://oss-cn-hangzhou.aliyuncs.com'
bucket_name = 'chatbot-backups'

# 创建Bucket
auth = oss2.Auth(access_key_id, access_key_secret)
bucket = oss2.Bucket(auth, endpoint, bucket_name)

# 创建备份文件
date_str = datetime.datetime.now().strftime('%Y%m%d-%H%M%S')
backup_filename = f'backup-{date_str}.zip'

# 压缩备份目录
with zipfile.ZipFile(backup_filename, 'w', zipfile.ZIP_DEFLATED) as zipf:
    for root, dirs, files in os.walk('backups'):
        for file in files:
            file_path = os.path.join(root, file)
            arcname = os.path.relpath(file_path, 'backups')
            zipf.write(file_path, arcname)

# 上传到OSS
bucket.put_object_from_file(f'backups/{backup_filename}', backup_filename)

# 删除本地备份文件
os.remove(backup_filename)

print(f"备份上传成功: {backup_filename}")
```

## 6. 恢复方案

### 6.1 数据库恢复

#### 6.1.1 SQLite恢复
```bash
# 停止服务
python manage.py runserver --stop

# 恢复数据库
cp backups/db-backup-20260301-020000.sqlite3 db.sqlite3

# 启动服务
python manage.py runserver
```

#### 6.1.2 MySQL恢复
```bash
# 停止服务
python manage.py runserver --stop

# 恢复数据库
mysql -u [username] -p[password] [database_name] < backups/db-backup-20260301-020000.sql

# 如果是压缩文件
gunzip -c backups/db-backup-20260301-020000.sql.gz | mysql -u [username] -p[password] [database_name]

# 启动服务
python manage.py runserver
```

### 6.2 文件恢复

```bash
# 解压文件备份
tar -xzf backups/files/avatars-20260301-020000.tar.gz -C media/

# 解压上传文件
tar -xzf backups/files/uploads-20260301-020000.tar.gz -C media/
```

### 6.3 配置恢复

```bash
# 恢复环境变量
cp backups/config/.env-20260301-020000 .env

# 恢复Django配置
cp backups/config/settings.py-20260301-020000 config/settings.py

# 重新加载配置
python manage.py runserver
```

## 8. 备份监控

### 8.1 备份状态监控

**监控脚本** (`monitor_backup.sh`):
```bash
#!/bin/bash

# 检查最新备份
LATEST_DB=$(ls -t backups/db-backup-*.sql.gz 2>/dev/null | head -1)
LATEST_FILES=$(ls -t backups/files/*.tar.gz 2>/dev/null | head -1)

# 检查备份时间
DB_AGE=$(stat -c %Y $LATEST_DB 2>/dev/null)
FILES_AGE=$(stat -c %Y $LATEST_FILES 2>/dev/null)
CURRENT_TIME=$(date +%s)

DB_DAYS=$(( (CURRENT_TIME - DB_AGE) / 86400 ))
FILES_DAYS=$(( (CURRENT_TIME - FILES_AGE) / 86400 ))

echo "数据库备份: $LATEST_DB (${DB_DAYS}天前)"
echo "文件备份: $LATEST_FILES (${FILES_DAYS}天前)"

# 检查备份大小
if [ -f "$LATEST_DB" ]; then
    DB_SIZE=$(du -h $LATEST_DB | cut -f1)
    echo "数据库备份大小: $DB_SIZE"
fi

if [ -f "$LATEST_FILES" ]; then
    FILES_SIZE=$(du -h $LATEST_FILES | cut -f1)
    echo "文件备份大小: $FILES_SIZE"
fi

# 告警
if [ $DB_DAYS -gt 7 ]; then
    echo "⚠️ 数据库备份超过7天，请检查备份任务"
fi

if [ $FILES_DAYS -gt 7 ]; then
    echo "⚠️ 文件备份超过7天，请检查备份任务"
fi
```

## 9. 备份策略总结

### 9.1 备份频率

| 数据类型 | 备份频率 | 保留时间 | 存储位置 |
|---------|---------|---------|---------|
| 数据库 | 每天1次 | 7天 | 本地 + 云存储 |
| 文件 | 每周1次 | 30天 | 本地 + 云存储 |
| 配置 | 变更时 | 永久 | 版本控制 |
| 日志 | 每天1次 | 30天 | 本地 |

### 9.2 存储位置

- **本地存储**: 服务器本地磁盘
- **异地存储**: 远程服务器
- **云存储**: 阿里云OSS/腾讯云COS/AWS S3
- **版本控制**: Git仓库

### 9.3 恢复时间目标(RTO)

| 恢复类型 | RTO | RPO |
|---------|-----|-----|
| 数据库 | < 30分钟 | < 24小时 |
| 文件 | < 1小时 | < 7天 |
| 配置 | < 10分钟 | 实时 |
