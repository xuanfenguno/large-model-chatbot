## 一、后端核心代码文件

### 1.1 数据模型层

**文件路径**：`backend/chatbot/models.py`

**功能说明**：定义系统的所有数据模型，包括用户、会话、消息、语音通话记录等。

**包含的模型**：
- `PasswordResetToken` - 密码重置令牌
- `Conversation` - 会话模型
- `Message` - 消息模型
- `UserProfile` - 用户配置
- `VoiceCallRecord` - 语音通话记录

---

### 1.2 视图层（核心API接口）

**文件路径**：`backend/chatbot/views.py`

**功能说明**：实现所有RESTful API接口，包括聊天、流式聊天、用户认证等。

**核心接口**：
- `health_check` - 健康检查
- `chat` - 非流式聊天接口
- `stream_chat` - 流式聊天接口（SSE）

---

### 1.3 API基类（AI模型调用）

**文件路径**：`backend/chatbot/api_base.py`

**功能说明**：实现所有AI模型的API调用逻辑，支持OpenAI、Qwen、DeepSeek等多种模型。

**核心类**：
- `BaseAIApi` - API基类
- `OpenAIApi` - OpenAI API实现
- `QwenApi` - 通义千问API实现（支持多模态）
- `DeepSeekApi` - DeepSeek API实现
- `EnhancedApiWrapper` - 增强API包装器

**核心方法**：
- `_convert_local_image_to_base64` - 本地图片转Base64
- `send_message` - 发送消息
- `send_message_stream` - 流式发送消息
- `_send_multimodal_stream` - 多模态流式请求
- `_send_multimodal_non_stream` - 多模态非流式请求

---

### 1.4 增强API包装器

**文件路径**：`backend/chatbot/enhanced_api.py`

**功能说明**：提供API密钥检查、模型切换、模拟响应等功能。

**核心功能**：
- `get_available_providers` - 获取可用API提供商
- `has_any_api_key` - 检查API密钥
- `get_available_models` - 获取所有可用模型
- `create_api_instance` - 创建API实例
- `MockApiInstance` - 模拟API实例（无密钥时使用）

---

### 1.5 URL路由配置

**文件路径**：`backend/chatbot/urls.py`

**功能说明**：配置所有API路由。

**核心路由**：
- `/api/v1/chat/` - 非流式聊天
- `/api/v1/stream-chat/` - 流式聊天
- `/api/v1/models/` - 可用模型列表
- `/api/v1/login/` - 用户登录
- `/api/v1/register/` - 用户注册
- `/api/v1/conversations/` - 会话管理
- `/api/v1/voice/` - 语音通话
- `/api/v1/knowledge-base/` - 知识库

---

### 1.6 Django全局配置

**文件路径**：`backend/config/settings.py`

**功能说明**：Django项目的全局配置，包括数据库、中间件、CORS、AI模型配置等。

**核心配置项**：
- `DATABASES` - 数据库配置
- `INSTALLED_APPS` - 已安装应用
- `MIDDLEWARE` - 中间件配置
- `CORS_ALLOWED_ORIGINS` - CORS配置
- `LLM_CONFIG` - AI模型配置

---

### 1.7 序列化器

**文件路径**：`backend/chatbot/serializers.py`

**功能说明**：数据序列化，用于API请求和响应的数据转换。

---

### 1.8 功能路由器

**文件路径**：`backend/chatbot/function_router.py`

**功能说明**：实现17种AI功能的路由，包括代码生成、翻译、摘要等。

---

### 1.9 语音通话视图

**文件路径**：`backend/chatbot/voice_views.py`

**功能说明**：实现语音通话相关API。

**核心接口**：
- `initiate_call` - 发起通话
- `answer_call` - 接听通话
- `reject_call` - 拒绝通话
- `end_call` - 结束通话
- `get_call_status` - 获取通话状态

---

### 1.10 知识库视图

**文件路径**：`backend/chatbot/knowledge_base_views.py`

**功能说明**：实现知识库管理API。

**核心接口**：
- `search_knowledge_base` - 搜索知识库
- `add_to_knowledge_base` - 添加到知识库
- `delete_from_knowledge_base` - 删除知识库
- `sync_knowledge_base` - 同步知识库

---

### 1.11 中间件

**文件路径**：`backend/chatbot/middleware/`

**包含文件**：
- `rate_limit.py` - 速率限制中间件
- `ErrorHandlingMiddleware.py` - 错误处理中间件

---

### 1.12 全局中间件

**文件路径**：`backend/middleware/cache_middleware.py`

**功能说明**：缓存中间件，用于API响应缓存。

## 六、系统架构说明

### 技术栈

| 层级 | 技术 | 说明 |
|------|------|------|
| 前端 | Vue 3 + Element Plus + Vite | 单页应用 |
| 后端 | Django 4.2 + Django REST Framework | RESTful API |
| 数据库 | MySQL | 关系型数据库 |
| AI模型 | 阿里云百炼 Qwen-VL-Max | 多模态AI |
| 实时通信 | SSE (Server-Sent Events) | 流式响应 |

### 核心功能

1. **文字对话** - 支持多轮对话，上下文记忆
2. **图片识别** - 支持图片上传和AI识别
3. **语音通话** - 支持语音通话功能
4. **视频通话** - 支持视频通话功能
5. **知识库** - 支持知识库管理和检索
6. **多模型支持** - 支持OpenAI、Qwen、DeepSeek等多种AI模型

### 数据流

```
用户输入 → 前端Vue组件 → Pinia状态管理 → Axios请求 → Django API视图 → 
AI模型调用 → 响应处理 → SSE流式返回 → 前端显示
```
