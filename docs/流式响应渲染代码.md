# 流式响应渲染核心代码

## Chat.vue - 流式响应核心实现

```javascript
// 发送消息（流式响应）
const sendMessageStream = async (content, model = null) => {
  chatStore.isStreaming.value = true
  let aiMessage = null

  try {
    // 自动创建新会话
    if (!chatStore.selectedConversationId.value) {
      const newConversation = await chatStore.createConversation(content.slice(0, 30) + '...')
    }

    // 创建用户消息
    const userMessage = {
      id: Date.now(),
      role: 'user',
      content: content,
      created_at: new Date().toISOString()
    }
    chatStore.messages.value.push(userMessage)
    
    // 创建AI回复占位消息
    aiMessage = {
      id: Date.now() + 1,
      role: 'assistant',
      content: '',
      is_loading: true,
      is_streaming: true
    }
    chatStore.messages.value.push(aiMessage)

    // 构建对话历史
    const history = chatStore.messages.value
      .filter(msg => msg.id !== aiMessage.id)
      .map(msg => ({ role: msg.role, content: msg.content }))

    // 流式发送消息
    await aiApi.sendMessageStream(
      content,
      { model, history, conversation_id: chatStore.selectedConversationId.value },
      // 数据块回调：逐段渲染
      (chunk) => {
        const aiIndex = chatStore.messages.value.findIndex(msg => msg.id === aiMessage.id)
        if (aiIndex !== -1) {
          chatStore.messages.value[aiIndex].content += chunk
        }
      },
      // 完成回调
      async (result) => {
        const aiIndex = chatStore.messages.value.findIndex(msg => msg.id === aiMessage.id)
        if (aiIndex !== -1) {
          chatStore.messages.value[aiIndex].is_loading = false
          chatStore.messages.value[aiIndex].is_streaming = false
        }
      }
    )
  } catch (error) {
    // 错误处理
  } finally {
    chatStore.isStreaming.value = false
  }
}
```

## 核心技术说明

1. **流式请求**：使用 `sendMessageStream` 方法发起流式请求
2. **逐段渲染**：通过 `chunk` 回调实时更新AI回复内容
3. **状态管理**：使用 Pinia 状态管理会话和消息
4. **对话历史**：自动构建对话历史，支持多轮对话

## 使用场景

- 大模型长文本生成
- 实时对话交互
- 多轮对话上下文管理
