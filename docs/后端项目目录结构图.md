## 后端项目模块说明

### 1. chatbot/ - 核心聊天业务模块

这是项目的核心应用模块，包含以下功能：

**核心文件**：
- `models.py` - 定义5个数据模型（Conversation、Message、UserProfile等）
- `views.py` - 实现认证、聊天、会话等API视图
- `serializers.py` - 数据序列化器
- `urls.py` - API路由配置

**功能模块**：
- `enhanced_api.py` - 多模型API支持（6个AI模型）
- `function_router.py` - 17种AI功能路由
- `knowledge_base_views.py` - 知识库管理
- `voice_views.py` - 语音通话功能

**中间件**：
- `ErrorHandlingMiddleware.py` - 错误处理中间件
- `rate_limit.py` - 速率限制中间件

**工具**：
- `utils/` - 数据库优化、知识库工具
- `management/commands/` - Django管理命令

### 2. config/ - 项目配置模块

**核心配置**：
- `settings.py` - Django全局设置
- `urls.py` - 主URL路由
- `asgi.py` / `wsgi.py` - 服务器配置
- `cache_config.py` - 缓存配置
- `celery.py` - 异步任务配置

### 3. middleware/ - 全局中间件

- `cache_middleware.py` - 缓存中间件

### 4. scripts/ - 脚本目录

包含各种启动和维护脚本

### 5. tests/ - 测试目录

- `tests.py` - 单元测试
- `performance_test.py` - 性能测试

### 6. chroma_data/ - 向量数据库

Chroma向量数据库的数据存储目录

## 制作截图的方法

### 方法1：使用VS Code的文件资源管理器

1. 在VS Code中打开项目
2. 展开 `backend` 目录
3. 使用截图工具截取文件资源管理器区域
4. 保存为图片

### 方法2：使用Tree命令生成可视化

在PowerShell中运行：

```powershell
# 安装Tree模块（如果需要）
Install-Module -Name Tree

# 生成目录树
tree g:\Phe\PycharmProjects\PythonProject\chat\backend /F /A
```

### 方法3：使用draw.io绘制

1. 打开 https://app.diagrams.net/
2. 使用文件夹和文件图标绘制目录树
3. 导出为PNG或PDF
